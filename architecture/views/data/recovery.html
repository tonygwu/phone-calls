[calls] Call tasks

table · existing · verified

Store: SQLite storage [storage] · Table: calls

Where this data travels

  • Durable call coordinator -> SQLite storage: Persist before the provider request [persist]

Fields and constraints

  • id TEXT PRIMARY KEY
  • request_hash TEXT UNIQUE NOT NULL
  • created INTEGER NOT NULL; UTC acceptance milliseconds
  • expires INTEGER NOT NULL; created plus 30 days
  • month TEXT NOT NULL; UTC month
  • active INTEGER NOT NULL
  • next_check INTEGER NOT NULL
  • allowance INTEGER NOT NULL; USD microdollars
  • body TEXT NOT NULL; Task JSON

[initiation] Fresh provider conversation

json · existing · verified

Where this data travels

  • Durable call coordinator -> ElevenLabs telephone agent: Initiate once with fresh context [start]
  • Input to ElevenLabs telephone agent [voice-agent]

Fields and constraints

  • agent_id, agent_phone_number_id, to_number: configured identities and validated destination
  • conversation_initiation_client_data.user_id: durable call UUID
  • conversation_initiation_client_data.dynamic_variables: task_type, objective, context, owner_name, callback_number, voicemail_action/message
  • success_criteria and all constraints arrays are JSON-encoded strings inside dynamic_variables
  • conversation_config_override.conversation.max_duration_seconds: approved duration
  • call_recording_enabled: false
  • telephony_call_config.ringing_timeout_secs: 60

[provider-conversation] Raw ElevenLabs conversation

json · existing · verified

Where this data travels

  • Durable call coordinator -> ElevenLabs telephone agent: Read conversation; returns raw provider evidence [evidence]
  • Output from ElevenLabs telephone agent [voice-agent]

Fields and constraints

  • agent_id, conversation_id, user_id: identities
  • status: initiated, in-progress, processing, done or failed
  • metadata: start_time_unix_secs, call_duration_secs, cost_fiat, Twilio phone identity
  • transcript: timed role/message/tool turns
  • analysis: summary and collected outcome/confirmation/unresolved values
  • has_audio: recording availability

[admission] Provider admission facts

json · existing · verified

Where this data travels

  • Durable call coordinator -> ElevenLabs telephone agent: Check agent, number and credits before admission [admit-eleven]
  • Durable call coordinator -> Twilio telephone connection: Check account, routing, balance and current rate before admission [admit-twilio]

Fields and constraints

  • ElevenLabs reads: complete agent configuration, phone assignment, subscription credits
  • Twilio reads: account identity/type, number primary/fallback routing, USD balance, destination USD rate
  • Seven concurrent read responses; invalid or unavailable facts reject admission before a task exists
