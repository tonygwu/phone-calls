# Limits and recovery behavior

Only the configured owner is accepted. The Worker checks the signed Access issuer, audience, expiry, email and subject. It rejects other hostnames and browser origins. The two provider paths are exact matches and accept only signed POST requests. Recordings stream from ElevenLabs through an authenticated route and are never copied into another object store. Twilio recording is disabled.

There is one active call at a time. An uncertain dispatch occupies that slot. Each task is persisted before the one outbound POST. Reconciliation may read providers repeatedly, but it never retries that POST. A pending task older than 60 seconds expires without dialing because its admission check may be stale. Cancellation and the watchdog use Twilio's call status and request termination; neither reports success until a subsequent provider read proves a terminal status.

Reminder calls default to and are limited to 180 seconds. Other calls default to 900 seconds with an absolute 1,800-second maximum. Ringing is limited to 60 seconds. The agent receives the conversation duration override, and the durable watchdog starts at dispatch plus ringing plus allowed duration. Active calls are checked every 15 seconds, including during provider failures. While any call is active, terminal analysis and price recovery are deferred. Otherwise one background task runs per alarm, using one-minute checks for the first day and hourly checks afterward. Provider requests time out after 15 seconds. Infrastructure outages and a background request already in flight can delay watchdog execution; the independent ElevenLabs duration limit is therefore also required.

The additional monthly budget is $10, accounted by UTC calendar month. Fixed costs and known taxes/hosting costs must be explicitly quoted. Twilio destination rates and balances are read before each call; ElevenLabs included credits and the pinned agent configuration are also checked. The destination-rate request includes the configured caller number. The response must identify both exact numbers and return one outbound price after filtering; missing or multiple prices block admission instead of choosing a rate. The operator-supplied allowance for ElevenLabs/LLM/analysis and fixed costs expires within 24 hours. This deliberately blocks dialing if current non-Twilio costs have not been verified; it requires quote refresh before continued production use. There are no automatic top-ups or billing upgrades. Prepaid funding requirements are separate from incurred charges and must fit the user's authorization.

Reservations cover the rounded-up maximum number of minutes. Unknown or provisional charges retain the allowance. Only when each provider supplies a non-null price in a terminal response does its price count as final evidence. A later terminal response with no price cannot promote an earlier estimate; polling and the reservation continue. Once both providers supply this final evidence, the ledger uses the Twilio USD charge and conservatively counts ElevenLabs' total fiat cost, even if included subscription credits cover some of it. A durable sequence number orders overlapping provider reads; an older response cannot replace a newer result. Final state never regresses to processing. Reported charges never decrease automatically, so refunds require operator reconciliation. These choices may block calls earlier than actual additional spending would require. A quote is an admission bound, not a provider-side spending lock. If a final charge exceeds the allowance, it remains visible and reduces the remaining budget.

Task briefs, results and transcripts expire after 30 days from task acceptance. If a call is still unresolved at expiry, its content is deleted and a content-free safety lock blocks new calls until an operator reconciles the provider. Hashes of used request IDs remain so an ancient retry cannot dial again. Aggregate monthly charge totals also remain; neither retained structure contains the brief, number, transcript or recording. Use random UUIDs as request IDs. ElevenLabs separately deletes its audio and transcripts after 30 days. Changing that setting or the saved agent configuration makes the hash check fail closed.

The MCP request-body limit is 64 KiB. Webhook bodies are limited to 2 MiB; audio webhooks are not enabled. Tool descriptions expose field lengths, a maximum of 100 history rows or transcript turns per page, and the returned cursor/offset. Transcript pagination reports the total and the next offset; nothing is silently summarized in place of transcript text. Provider lookup returns at most 100 matching conversations and refuses ambiguous or truncated results instead of guessing a call identity.

Task errors use explicit categories, including `SETUP_REQUIRED`, `IDENTITY_MISMATCH`, `CONFIG_DRIFT`, `PRICING_UNKNOWN`, `BUDGET_EXHAUSTED`, `DISPATCH_UNKNOWN`, `TERMINATION_UNCONFIRMED`, and `RETENTION_UNRESOLVED`. Provider error bodies and credentials are not returned. Cloudflare request logging is disabled in the deployment configuration. Inspect sanitized call IDs, state transitions and error categories through the authenticated tools.
