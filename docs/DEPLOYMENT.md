# Configure and deploy privately

The service uses a new Worker, a new dedicated Twilio number, a new ElevenLabs agent and three new Access applications. It does not edit the existing digital-twin service. The main Access application protects the hostname with Managed OAuth and an owner-only policy. Two more specific applications bypass interactive login only for the exact signed callback paths. Worker code verifies the provider signatures; every other route validates the owner's Access JWT.

1. Copy `.dev.vars.example` to `.dev.vars`, set mode `600`, and fill in provider credentials locally. Never put secrets in a tool argument, chat, a plugin manifest or source control. `private/` and `.dev.vars` are ignored.
2. Run `npm run preflight`, then `npm run inspect:accounts`. Inspect the full raw responses under `private/account-evidence/` and verify the selected Twilio account and ElevenLabs user/workspace. A paid ElevenLabs subscription alone does not establish the current Agents allowance. Check the Agents billing page, credits, model charges and retention entitlement.
3. Sign into Cloudflare with `node_modules/.bin/cf auth login --no-browser`, or provide an account-scoped API token. `cf` has separate authentication from Wrangler. Verify `cf auth whoami`. Required administration permissions cover Workers, Durable Objects, the chosen DNS zone, and Access applications and policies. Do not deploy to a temporary account.
4. Find an available **local US voice number** in the selected Twilio account. Verify the rental price through Twilio's Pricing API and confirm the account's funding requirements. The provisioning script requires an active paid account. It will not upgrade a trial account or top up a balance. If the required deposit exceeds the user's additional budget, obtain a concrete budget decision first.
5. Copy `examples/setup.json` to `private/setup.json`. Resolve every placeholder from account evidence, including the exact Access user subject and email, the Zero Trust issuer, Cloudflare account and hostname, stock voice ID, selected number, rental rate, maximum per-minute/per-call allowance, credits and known taxes/hosting costs. Null prices intentionally fail validation. The configured cost allowances remain in effect until changed; live destination rates, credits and balances are checked automatically before each call. No daily renewal is required. Verify the actual ChatGPT OAuth redirect URI during connection and include only that URI. Localhost and loopback redirects support the two CLI clients.
6. Run `npm run provision:prepare`. It writes `private/provision-plan.json` with exact resource bodies and a SHA-256. Obtain a fresh adversarial `ship` review before external changes. Save `{ "verdict": "ship", "planSha256": "<reviewed hash>" }` as `private/provision-review.json`. This records the review; it is not a replacement for conducting it.
7. Run `npm run provision:apply`. The script checks account identity and current number rental, creates the resources, imports the number with SMS disabled, reapplies rejecting inbound routing, reads back the agent and writes private Worker secrets. Each mutation is journaled before sending. An ambiguous result stops the script and must be reconciled before resuming; never delete an uncertain journal entry just to retry.
8. Read back all three Access applications, including policies and exact domains; agent authentication, prompt, model, disabled fallback, stock voice, max-duration override and 30-day privacy settings; ElevenLabs phone assignment and webhook status; Twilio number routing and empty SMS/fallback routes. The agent hash pins the provider configuration. Three known provider defaults are treated as absent: null `non_sensitive_value` in analysis entries, empty `conversation_config.asr.keyterm_libraries`, and true `platform_settings.widget.transcript_speech_sync_enabled`. Non-default values and other fields still affect the hash. Verify the Owner subject using a signed Access assertion. Record sanitized IDs and checks, not credentials.
9. Build with `PHONE_CALLS_HOSTNAME=<chosen-hostname> npm run build`. Inspect `.cloudflare/output/v0/workers/default/worker.config.json`: the custom domain must match and both workers.dev and preview URLs must be disabled. Run `cf deploy --dry-run` and the local checks. A fresh deployment review must cover the exact build, secrets, account and readbacks. Save `private/deploy-review.json` with `verdict`, `buildSha256`, `secretsSha256`, `workerConfigSha256`, and `cloudflareAccountId`, then run `npm run deploy`.
10. Read back the deployed Worker and Access state. Verify unauthenticated management and recording requests are rejected, callbacks reject bad signatures, alternate deployment URLs do not work, and the owner's OAuth login reaches all five MCP tools. Call `phone_calls_get_setup`. Do not dial until readiness passes.

The deployment script never places a phone call. The first live call is a separate, reviewed test using the same MCP tool and the owner's allowlisted number.

If provisioning is interrupted, inspect `private/provision-journal.json` and the provider accounts. Reconcile a step marked `intent` by identifying the exact created resource and recording its verified result. Do not automatically repeat creates, purchases, imports or calls. To roll back, disable the new service's Access allow policy first, terminate any active call and verify it, then disable the new ElevenLabs agent. Release the dedicated number only after confirming it belongs exclusively to this service; deleting the local files does not stop number rental.

Official references: [Cloudflare MCP handler](https://developers.cloudflare.com/agents/model-context-protocol/apis/handler-api/), [Managed OAuth](https://developers.cloudflare.com/cloudflare-one/access-controls/applications/http-apps/managed-oauth/), [ElevenLabs outbound calls](https://elevenlabs.io/docs/api-reference/integrations/twilio/outbound-call), [signed webhooks](https://elevenlabs.io/docs/eleven-agents/workflows/post-call-webhooks), [Twilio signature verification](https://www.twilio.com/docs/usage/security).
