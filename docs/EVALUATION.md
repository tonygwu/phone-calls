# Evidence and rollout

Local tests run the production engine against SQLite in Cloudflare's actual local Workers runtime, with simulated provider responses. They cover input validation, owner authentication, signatures, budget admission, concurrency, retries, uncertain dispatch, callback races, restart recovery, cancellation, independent hangup during an ElevenLabs outage, duration enforcement, retention and real MCP HTTP tool dispatch. Provider-shape tests check account and destination identity and fail on absent required telemetry.

The first run attempted 24 tests: 22 succeeded and 2 failed. The failures exposed retention of unresolved private content and slower watchdog polling after a day. A later run exposed two more failures: ElevenLabs lookup errors could prevent a known Twilio call from being terminated, and delayed alarms could dial stale pending tasks. The corresponding tests failed before their fixes and passed afterward. A budget rounding assertion also caught a one-microdollar floating-point artifact; reservation arithmetic now adds integer microdollar components.

The independent review then exposed stale provider responses reducing accounted cost, expired details returned through duplicate starts, unsafe fallback routes accepted by preflight, and old background work delaying the active watchdog. Six committed regression tests failed before those fixes. Extra coverage checks two overlapping completed responses and alarm scheduling with deferred background work. Full command evidence and the original review are under `docs/evidence/` and `docs/reviews/`.

The scoped review of those fixes found that a provisional price could be treated as final when a later terminal response omitted the price. After the operator instructed continuation, two new regression cases failed for ElevenLabs and Twilio. The implementation now records terminal-price evidence for each provider, retains the reservation and polling until both are available, and preserves already obtained final evidence if a later response omits its price. `npm run check` reports 51 attempted, 51 succeeded, 0 failed, and a completed build. The focused independent review returned ship with zero findings. It reproduced both baseline failures, reran all 51 current tests, and passed 14 extra simulated cases covering zero prices, persistence and response ordering.

Simulated tests are evidence of the orchestration and boundaries they exercise. They do not prove that GPT-4.1 Mini follows the call instructions, that a carrier delivers audio, or that voicemail timing works.
