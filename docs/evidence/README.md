# Historical evaluation evidence

These files preserve sanitized command transcripts, provider summaries, and evaluation records from earlier releases.
Counts and behavior in an old log do not describe the current source.
See [the release review](../PUBLIC-RELEASE.md) for the latest local checks and remaining gaps.

Publication redactions replace local checkout paths with `<repo>`, home paths with `<home>`, and external skill paths with `<architecture-skill>`.
Historical personal service hostnames use `calls.example.com` instead.
These replacements preserve test results but mean the affected transcripts are not byte-for-byte raw responses.
Raw provider responses, real call content, and original screenshots stay outside Git.
